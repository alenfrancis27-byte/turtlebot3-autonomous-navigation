# turtlebot3-autonomous-navigation
Autonomous navigation using ROS 2 Nav2 Rviz and Gazebo

Project Description:
This project demonstrates autonomous navigation of a TurtleBot3 robot in a Gazebo simulation environment using ROS 2 and the Navigation2 (Nav2) stack.

Objectives:
Simulate TurtleBot3 in Gazebo.
Configure ROS 2 Navigation2.
Visualize robot navigation using RViz.
Perform autonomous navigation.
Avoid obstacles and reach target destinations.

Technologies Used:
ROS 2
TurtleBot3
Gazebo
RViz2
Navigation2 (Nav2)
Ubuntu Linux

Setup Instructions:
Install ROS 2.
Install TurtleBot3 packages.
Configure the TurtleBot3 model.
Launch Gazebo simulation.
Launch Nav2.
Set a navigation goal in RViz.
